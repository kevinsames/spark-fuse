# Release v1.3.0 (2026-04-10)

## Highlights
- PySpark Structured Streaming support for `change_tracking` via `foreachBatch`.
- Spark Declarative Pipelines (`pyspark.pipelines`) integration with decorator helpers.
- All public change tracking symbols now importable directly from `spark_fuse.utils`.

## Upgrade Notes
- No breaking changes. Existing batch APIs (`current_only_upsert`, `track_history_upsert`,
  `apply_change_tracking`, `df.change_tracking`, `df.write.change_tracking`) are unchanged.
- `df.writeStream.change_tracking` is now registered automatically on import alongside the
  existing batch accessors.

## Detailed Changes

### Added
- `StreamingChangeTrackingWriter` — picklable `foreachBatch` callable that applies change
  tracking merge semantics to each micro-batch, with built-in idempotency.
- `StreamingChangeTrackingBuilder` — fluent streaming API:
  `df.writeStream.change_tracking.options(...).toTable(name, checkpoint=...)`.
- `streaming_change_tracking_writer(df)` factory function.
- `DataStreamWriter.change_tracking` accessor registered by `enable_change_tracking_accessors()`.
- `change_tracking_table` decorator — combines `dp.create_streaming_table` + `dp.append_flow`
  with change tracking in a single decorator (requires `pyspark.pipelines`).
- `change_tracking_flow` decorator — registers a `dp.append_flow` with change tracking
  `foreachBatch` semantics (requires `pyspark.pipelines`).
- `create_change_tracking_table` helper — thin wrapper around `dp.create_streaming_table`.
- All public symbols re-exported from `spark_fuse.utils` (no sub-module import needed).
- Streaming and Declarative Pipelines sections added to `docs/guides/change_tracking_demo.md`.
